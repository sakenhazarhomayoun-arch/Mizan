# میزان — پروژه اولیه اندروید

این پوشه یک پروژه Android Studio برای تبدیل رابط HTML فعلی «میزان» به برنامه اندرویدی است.

## امکانات نسخه اولیه
- نگه‌داشتن رابط HTML و اکولایزر مبتنی بر Web Audio
- درخواست مجوز دسترسی به فایل‌های صوتی
- خواندن فهرست آهنگ‌ها از MediaStore اندروید
- نمایش آهنگ‌های شناسایی‌شده در فهرست پخش

## ساخت APK
1. Android Studio را روی کامپیوتر نصب کنید.
2. از مسیر **Open** همین پوشه `MizanAndroidProject` را باز کنید.
3. صبر کنید Gradle Sync کامل شود.
4. از منوی **Build > Build APK(s)** خروجی بگیرید.

## نکته مهم
این پروژه منبع اولیه است، نه APK آزمایش‌شده. پخش مستقیم URIهای `content://` در WebView و عملکرد اکولایزر باید روی گوشی واقعی تست شود؛ اگر WebView دستگاه پخش این URIها را نپذیرد، مرحله بعدی اتصال پخش‌کننده بومی اندروید خواهد بود. در این محیط خروجی APK کامپایل و روی دستگاه آزمایش نشده است.
