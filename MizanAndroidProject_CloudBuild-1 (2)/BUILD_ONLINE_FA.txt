راهنمای ساخت APK بدون نصب Android Studio روی لپ‌تاپ

این پروژه workflow ساخت آنلاین با GitHub Actions دارد و روی سرورهای GitHub اجرا می‌شود.

مراحل:
1. وارد حساب GitHub شوید یا حساب بسازید.
2. یک repository جدید بسازید؛ Public یا Private به انتخاب خودتان.
3. ZIP پروژه را روی کامپیوتر استخراج کنید.
4. همه فایل‌ها و پوشه‌های داخل پوشه MizanAndroidProject را در repository آپلود کنید. پوشه مخفی `.github` و فایل `.github/workflows/build-apk.yml` هم باید آپلود شوند.
5. به تب Actions بروید و workflow با نام `Build Mizan APK` را انتخاب کنید. اگر خودکار اجرا نشده، گزینه Run workflow را بزنید.
6. بعد از پایان موفقیت‌آمیز، صفحه اجرای workflow را باز کنید و از بخش Artifacts فایل `Mizan-debug-APK` را دانلود کنید.
7. فایل Artifact دانلودشده را از حالت ZIP خارج کنید؛ داخلش `app-debug.apk` است.
8. APK را به گوشی منتقل و نصب کنید. ممکن است لازم باشد به فایل‌منیجر اجازه نصب برنامه‌های ناشناس بدهید.

نکته‌ها:
- Android Studio روی ویندوز ۷ نصب نمی‌شود؛ کامپایل روی سرور آنلاین انجام می‌شود.
- حساب GitHub و اینترنت لازم است و ممکن است GitHub/Actions روی بعضی شبکه‌ها در دسترس نباشد.
- APK هنوز ساخته نشده؛ اول باید workflow با موفقیت اجرا شود.
- حتی اگر کامپایل موفق شود، پخش مستقیم URIهای آهنگ اندروید و اکولایزر باید روی گوشی واقعی آزمایش شود. این پروژه هنوز نسخه اولیه است.
